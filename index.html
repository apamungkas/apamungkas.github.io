Real-Time IoT Control System

An end-to-end two-way IoT demo. Telemetry streams from an M5Stack Fire through Azure IoT Hub into Microsoft Fabric for real-time dashboards, while control commands flow back — Fabric Activator triggers Power Automate and an Azure Function that invokes an IoT Hub Direct Method to drive the device's LED, buzzer & LCD.

Factory Digital Twin with Microsoft Fabric

An end-to-end digital twin for a fictitious manufacturer with 3 plants, 6 production lines, and 24 machines. A telemetry simulator feeds Microsoft Fabric Eventstream and Eventhouse, where KQL powers machine health, anomaly, and OEE insights. Fabric IQ models the factory ontology, while a real-time dashboard and Activator alerts bring operations to life.

SQL Server CDC Replication with Microsoft Fabric Pipeline

A one-way synchronization lab between two SQL Server 2022 Standard instances on Azure VMs. Native Change Data Capture (CDC) and a Fabric Data Factory pipeline move staged changes through a VNet data gateway, with stored procedures applying inserts, updates, and deletes, including supported keyless-table scenarios. Uses one-minute scheduled microbatches, not streaming or guaranteed one-minute lag. A synthetic-data proof-of-concept, not a production-ready replication service.

How the demos come together

These labs connect devices, factory assets, and databases through Azure and Microsoft Fabric — streaming telemetry, synchronizing data, modeling operations, and triggering action.

1

Capture

Devices and factory machines produce telemetry, while SQL Server CDC captures database changes.

2

Move

IoT Hub, Azure Functions, and Eventstream route telemetry; Fabric pipelines copy staged CDC events through a VNet data gateway.

3

Process

Eventhouse and digital twin models support telemetry analysis; stored procedures apply CDC batches to the destination SQL Server.

4

Act

Dashboards and Activator workflows support operational responses; CDC audit and reconciliation checks help verify the replicated data.
